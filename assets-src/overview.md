## rigid-bike-touring-bike

This is a 3D model of a rigid bike created in SolidWorks 2025. The dimensions are based on actual measurements from various brands, with some modifications added for creative exploration.

The model consists of ~270 components, including reverse-engineered parts such as the chain and rear derailleur. Materials like carbon steel and aluminium alloys were applied, while textures were adjusted for aesthetic purposes.

Repo owner notes: The rear derailleur is well modelled, with the only downside being the non-standard way the mech hanger is mounted (to the chainstay instead of near the dropout). Quick release axle.

## santa-cruz-v10-downhill-mountain-bicycle

## hardtail-by-fehe
Hello GrabCAD community! I'm excited to share this MTB model that I've been working on for a few months now. I relied on videos and pictures as references, so I essentially freestyled every component with the intention of making everything fit together, but every bit of factual information that I could find and fit into it, is implemented.
This model features wheelbase and the front triangle of an L-sized Rockhopper. Rear triangle was freestyled, with an attempt to make it look somewhat similar to the rear triangle of a Stanton Sherpa. It has 142mm dropouts. It was back and forth several times between 142 and 148, however, the last time I made a change it was set to 142mm, so I left it there.
Front and rear wheel hubs were inspired by some of the designs from DT Swiss. For the drivetrain, I opted for an Advent X rear derailleur with Advent X cassette. Unfortunately, I couldn't find enough visual references for the inner workings of the shifter that runs this drivetrain, so I went with a Shimano SLX 10-speed M670 shifter instead. In reality, these components shouldn't be compatible, but for the sake of this model, I had to make something.
I wanted everything to be mechanical, so I chose mechanical disc brakes and a coil spring front suspension. The suspension is one of the Suntour XCE models, with bottom case made for a 110x15 thru-axle. Brake rotors are 160mm Shimano DEORE XT Ice-Tech. Tires are Specialized Fast Trak Sport, pedals are from Chester, while brake calipers and the remaining components feature a generic design.
This entire project is like a big puzzle that's not quite finished, which is why I've named it "fv1". 

Repo owner notes: Contacted creator regarding usage rights. The model is very detailed and clean. It also has modelled the internals of some components, of which I find the shifter particularly interesting. It has a longer MTB derailleur, mechanical brakes, schrader valves, fast rolling MTB tires, forks that look to be in the range 120 - 140mm, ... the level of detail is astonishing but file size is huge, so that could come with challenges.
